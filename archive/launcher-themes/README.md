# Archived launcher themes

Truffled, Peak, gn-math 1 and gn-math 2, taken out of the launcher and kept here. Nothing in this folder is served.

The files are a snapshot of the launcher while it still had these themes. `style.css`, `index.html` and the files in `js/` are complete copies, not extracts, and `peak.js` and `gnmath.js` exist only here.

To bring the themes back, copy the snapshot over `public/launcher`:

- `index.html` and `style.css` to `public/launcher/`
- `js/*` to `public/launcher/js/`
- `fonts/*` to `public/launcher/fonts/`

That overwrites any launcher changes made since the snapshot, so merge the files by hand if the launcher has moved on.

The license for `fonts/gn.ttf` is unknown. It came from the gn-math HTML file.
